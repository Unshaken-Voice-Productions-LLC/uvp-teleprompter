# Contributing

Open an issue describing the problem and reproduction steps before a large change. Keep pull requests focused and include the checks you ran. Use synthetic examples only. Never attach customer records, credentials, private recordings, or internal business files.

Run `python -m unittest discover -s tests -v` from the repository root. See README for project-specific checks and known limitations. Security concerns belong in the private reporting channel listed in SECURITY.md.
