# Release checklist

- [x] Owner approved MIT licensing for the scoped UVP-owned material on 2026-11-13.
- [ ] Owner has approved merging the exact upgrade changes.
- [ ] CI tests and secret scan pass on the proposed commit.
- [ ] Review source files, examples, generated output and full Git history for sensitive material.
- [ ] Confirm documentation describes actual behavior and known limitations.
- [ ] Confirm asset and third-party rights, notices and attribution.
- [ ] Review optional dependency versions before packaging.
- [ ] Record the release tag, tested platforms, checks and rollback target.

A passing static scan is supporting evidence, not proof that all sensitive content or vulnerabilities have been excluded. Do not mark unperformed checks as complete.
